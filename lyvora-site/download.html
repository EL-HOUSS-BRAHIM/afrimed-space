Download APK ↓

A few simple steps.

  1. Download the APK on your Android phone.
  2. Open the file. If Android asks, allow installation from the browser or file manager you used.
  3. Install Lyvora Preview, then open it and create your account.

The preview uses a separate account from the regular Lyvora app. Most recent Android phones use ARM64.

Know what you’re downloading.

This is the signed preview installer from Lyvora’s published release. It is hosted here so you can download without a GitHub account.
